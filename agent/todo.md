### 최종 프로세스

1. 소스 결정
    - 추적할 채용 사이트/페이지 등록

2. 소스 실행
    - seed URL 접속
    - 목록/상세 페이지 탐색
    - 공고 링크 수집

3. 공고 추출
    - 제목, 회사, 본문, 기술스택, 마감일 등 추출

4. 정규화 및 저장
    - canonical URL 생성
    - content hash 생성
    - 기존 공고와 비교 후 upsert

5. 적합도 계산
    - 사용자 관심사 프로필 기반 점수화

6. 추천 여부 결정
    - 신규 공고인지
    - 이전 추천 공고인지
    - 내용이 갱신됐는지
    - 재노출 기간이 지났는지 판단

7. 추천 이력 저장
    - 추천 타입
    - 점수
    - 추천 이유
    - 추천 시점 저장

8. Digest 생성 및 메일링
    - 신규 / 갱신 / 재노출 공고 묶어서 발송
