# 최종 프로세스

## 1단계 목표

1. 소스 결정
    - 추적할 채용 사이트 및 페이지를 등록
    - 초기에는 하드코딩으로 시작하고, 추후 유저별 관리 방식으로 확장 검토

2. 소스 실행 및 공고 링크 수집
    - seed URL에 접속
    - Playwright MCP 기반으로 수집 진행
    - 현재는 별도 개발 리소스 없이 시작
    - 공고 링크 수집
        - 제목, 회사명, 마감일, 링크 추출
        - 본문은 제외
        - 회사명과 마감일 기준으로 1차 선별 수행

3. 수집 시점 기록
    - 다음 수집 시 현재 시점 이후 등록된 공고만 수집
    - 수집 시점은 회사별 업무시간을 고려해 결정
    - 별도 리소스 없이도 중복 수집을 줄일 수 있는 방향으로 설계

4. 메일 전송
   - 

5. 공고 및 추천 이력 저장
    - 간단한 데이터베이스 또는 파일 시스템 구축
    - 추후 분석 및 개선을 위해 저장된 데이터를 활용하도록 설계

## 2단계 목표

1. 본문 읽기
    - 공고 본문까지 수집
    - 본문이 이미지 기반인 경우 대응 방안 검토
    - 제목과 본문 형태로 정제
    - 공고 저장 또는 메일 발송을 위해 임시 저장 처리
    - ADK에서 바로 구조화 출력이 어려운 경우를 고려

2. 적합도 계산
    - AI 기반으로 공고와 사전 입력된 유저 정보를 비교해 적합도 산정

3. 추천 여부 결정
    - 신규 공고인지 판단
    - 이전에 추천한 공고인지 판단
    - 내용이 갱신되었는지 판단
    - 재노출 주기가 지났는지 판단

4. 추천 이력 저장
    - 추천 타입 저장
    - 추천 이유 저장
    - 추천 시점 저장

5. Digest 생성 및 메일링
    - 신규 / 갱신 / 재노출 공고를 묶어 Digest 생성 후 발송
